# Comidas Típicas

Este repositório contém um site estático sobre comidas típicas de diferentes culturas ao redor do mundo. O projeto foi desenvolvido com fins educativos, com o objetivo de colocar em prática conhecimentos de versionamento com Git e organização de trabalho em equipe, sob a orientação do professor Vedilson Prado.

## Objetivo do projeto

A proposta é apresentar pratos famosos de forma visual, organizada e interativa, ao mesmo tempo em que reforça conceitos de desenvolvimento web e boas práticas de uso do Git durante a criação do repositório.

## Funcionalidades

- Página inicial com destaque visual e listagem de pratos
- Páginas individuais para cada comida típica
- Conteúdo informativo com detalhes sobre origem, ingredientes e preparo
- Estilização responsiva e moderna com HTML, CSS e JavaScript
- Estrutura simples, sem dependências externas para rodar localmente

## Tecnologias utilizadas

- HTML5 para estrutura das páginas
- CSS3 para estilização e layout
- JavaScript para interatividade em elementos como modais
- Imagens e recursos estáticos localmente organizados

## Estrutura do repositório

```text
comidas-tipicas/
├── README.md
└── frontend/
    ├── index.html
    ├── images/
    ├── pages/
    ├── script/
    └── styles/
```

### Descrição das pastas

- frontend/index.html: página inicial do site
- frontend/pages/: páginas individuais de cada prato
- frontend/script/: arquivos JavaScript com a lógica de interação
- frontend/styles/: arquivos CSS responsáveis pela aparência do projeto
- frontend/images/: imagens utilizadas no projeto

## Pratos presentes no projeto

O site inclui páginas para pratos como:

- Sushi
- Feijoada
- Tacos
- Croissant
- Gelato
- Hidromel
- Paella
- Arroz frito
- Empanada
- Poutine

## Como executar localmente

Como o projeto é estático, não é necessário instalar dependências.

1. Acesse a pasta frontend
2. Abra o arquivo index.html em um navegador
3. Ou utilize uma extensão como Live Server no VS Code para visualizar melhor o projeto

## Como navegar

- Na página inicial, você encontra a lista de pratos disponíveis
- Ao acessar uma página específica, é possível visualizar informações detalhadas sobre a culinária correspondente

## Observações

Este projeto é uma implementação inicial de um site temático, com foco em apresentação visual e conteúdo educativo sobre gastronomia mundial. Ele também representa uma atividade prática de aprendizagem, desenvolvida com apoio do professor Vedilson Prado para explorar Git, estrutura de projetos e colaboração.
